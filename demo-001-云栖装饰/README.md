# demo-001 · 云栖装饰（官网 + 后台 + 数据看板）

> 作品集第 1 号。给客户看的东西：**不是"我会写代码"，是"你现在就能点开、能填表、后台能看到"。**

## 怎么看

双击 `index.html` 就行。不需要装任何东西、不需要联网、不需要构建。

三个页面互相是通的：

1. **index.html** — 官网。往下滚到「约个免费量房」，随便填一个手机号提交。
2. **admin.html** — 后台。刚提交的那条会出现在列表最上面。
3. **dashboard.html** — 数据看板。趋势、来源、漏斗、渠道成交率全是从同一份数据算出来的。

**这一套演示的是闭环：客户留电话 → 销售看到 → 老板看到数据。** 单做一个漂亮首页，客户不会掏钱；能看到"线索落进表格、数字自动汇总"，才会。

## 三个页面各自在证明什么

| 页面 | 证明给客户看的东西 | 对应报价档位 |
|---|---|---|
| 官网 | 你的店能有个不丢人的门面，手机上能看、能留电话 | 官网+后台 2000 |
| 后台 | 客户留的电话不用手抄，自动进表，能搜能改能导出 | 官网+后台 2000 |
| 看板 | 花钱投的哪个渠道有用，一眼能看出来 | 三件套 4500 |

## 改成客户自己的，要改哪里

全部是纯静态文件，改完直接传空间即可。**熟练的话 2 小时以内**：

1. **品牌色**：`assets/style.css` 最上面 `--brand` / `--brand-2` 两个变量。
2. **店名/电话/地址**：搜 `云栖装饰` 全局替换；页脚的营业时间在 `index.html` 底部。
3. **照片**：`index.html` 里三处 `.ph` 是 CSS 渐变占位，换成 `<img>` 或 `background-image` 就行。
4. **案例文字**：`#works` 那三张卡的标题和描述。
5. **报价三档**：`#price` 里三个 `.plan`，改数字和条目。
6. **小区/表单选项**：`index.html` 的 `<select id="f-budget">`。

## 技术说明（给懂的人看）

- 纯 HTML + CSS + 原生 JS，**零依赖、零构建**。没有 jQuery，没有 CDN，断网也能跑。
- 数据层在 `assets/app.js` 的 `Store` 对象里，用 `localStorage` 存。**真交付时只替换这一个对象**，改成 `fetch('/api/leads')` 即可，三个页面一行不用动。
- 图表是手写 SVG（`dashboard.html` 底部），不引 ECharts，因为引了就要多给你 300KB 和维护成本。
- 导出 CSV 带 BOM，Excel 直接打开不乱码。

## 部署（客户要上线时）

- 不想备案：Cloudflare Pages / Vercel / Netlify，拖文件夹进去，2 分钟出网址。
- 要国内速度：阿里云/腾讯云轻量 + 静态托管，**域名要备案**（7–20 个工作日，提前说清楚）。
- 想要后台真的多人共用：把 `Store` 换成接口 + 一个轻后端（Node/Python 都行），或者直接上 Supabase。

## 已知局限（跟客户必须说的）

- 这套是演示版：数据存在**本机浏览器**，换电脑/清缓存就回到初始样例，也不支持多人同时用。
- 真上线要接数据库。**这是报价里"标准版/进阶版"和"演示版"的差别**，一开始就讲清，别等交付才说。
