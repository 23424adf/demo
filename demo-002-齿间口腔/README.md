# demo-002 · 齿间口腔（官网 + 后台 + 数据看板）

> 作品集第 2 号。**同一套代码，第二天换了个行业。**
> 目的是回答客户那句最常问的话："你是不是只会做装修？"

## 跟 001 的差别

| | 001 云栖装饰 | 002 齿间口腔 |
|---|---|---|
| 行业 | 家装 | 齿科诊所 |
| 卖点 | 把工序写进合同 | 报价单逐项写清、免费拍片 |
| 后台字段 | 小区 / 预算 | 意向项目 / 预估客单 |
| 状态流 | 待跟进 → 已联系 → 已成交 | 待跟进 → 已联系 → **已到院** → 已成交 |
| 客单价 | 8–38 万 | 800–2.5 万 |

**改了什么**：一份 CSS 没动，`assets/app.js` 里换了 4 个常量（数据键、渠道、项目列表、客单档位），
三个 HTML 换了文案和字段名。**实际工时 40 分钟。**

## 为什么选口腔而不是随便换个店

1. 客单价高，老板愿意为"看起来专业"掏钱。
2. 行业里最怕的是"临时加项"，所以"报价单逐项写清 + 中途加项必须签字"就是天然卖点。
3. 牙科诊所的官网普遍很丑，且大多没有预约表单——**这是能一眼看出的落差**。

## 给客户看的时候怎么说

> "这是同一个系统的两个行业版本。装修的看这个，看牙的看这个。
> 你告诉我是做什么的，我按你的行业把字段和话术改掉——不是套模板，是同一套骨架换骨肉。"

## 已知局限

- 同样是演示版：数据存本机，多人不能同时用；真上线要接数据库。
- 没有真实的患者授权图片，案例位是占位块，交付时要客户提供。
